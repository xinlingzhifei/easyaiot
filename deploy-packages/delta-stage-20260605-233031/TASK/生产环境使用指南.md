# 🚀 AI视频监控系统 - 生产环境使用指南

## 📊 系统架构

```
摄像头(RTSP) → TASK(AI检测+编码) → ZLM(流媒体服务) → 前端(HTTP-FLV播放)
                    ↓
                报警回调 → DEVICE模块
```

**性能指标：**
- ✅ 视频延迟：~1秒（实时监控完全够用）
- ✅ 视频质量：2.5Mbps H.264 高清
- ✅ AI推理：YOLOv11 实时检测
- ✅ 并发能力：支持多路摄像头

---

## ⚙️ 配置说明

### 核心配置文件：`TASK/config/test.ini`

```ini
[video]
rtsp_url=rtsp://admin:password@192.168.1.100/stream
rtmp_url=rtmp://127.0.0.1/live/stream_test
width=1920
height=1080
fps=25

[features]
enable_rtmp=true      # 启用RTMP推流
enable_ai=true        # 启用AI检测
enable_alarm=true     # 启用报警

[ai]
enable=true
model_path=weights/yolo11n.onnx
threads=3

[alarm]
confidence_threshold=0.5    # 置信度阈值
cooldown_time=5             # 报警冷却时间（秒）
hook_url=http://192.168.1.10:1880/api/alarm/callback  # 报警回调地址
```

## 🔧 常见操作

### 修改视频源

编辑 `config/test.ini`：
```ini
[video]
rtsp_url=rtsp://your_camera_ip/stream
```

### 修改推流地址

```ini
[video]
rtmp_url=rtmp://127.0.0.1/live/your_stream_name
```

对应的播放地址：
```
http://127.0.0.1/live/your_stream_name.flv
```

### 调整AI检测灵敏度

```ini
[alarm]
confidence_threshold=0.7  # 0-1之间，越大越严格
```

### 更换AI模型

```ini
[ai]
model_path=weights/yolo11s.onnx  # s=小模型，m=中等，l=大模型
```

## 🎨 前端集成示例

### 使用 flv.js 播放

```html
<!DOCTYPE html>
<html>
<head>
    <title>AI视频监控</title>
    <script src="https://cdn.bootcdn.net/ajax/libs/flv.js/1.6.2/flv.min.js"></script>
</head>
<body>
    <video id="videoElement" width="1280" height="720" controls></video>
    
    <script>
        if (flvjs.isSupported()) {
            var videoElement = document.getElementById('videoElement');
            var flvPlayer = flvjs.createPlayer({
                type: 'flv',
                url: 'http://127.0.0.1/live/stream_test.flv',
                isLive: true,
                hasAudio: false  // 根据实际情况设置
            }, {
                enableWorker: true,
                enableStashBuffer: false,  // 禁用缓存降低延迟
                stashInitialSize: 128,
                lazyLoad: false,
                autoCleanupSourceBuffer: true
            });
            
            flvPlayer.attachMediaElement(videoElement);
            flvPlayer.load();
            flvPlayer.play();
        }
    </script>
</body>
</html>
```

### 多路视频墙（4路）

```html
<div style="display: grid; grid-template-columns: 1fr 1fr; gap: 10px;">
    <video id="video1" width="640" height="360" controls></video>
    <video id="video2" width="640" height="360" controls></video>
    <video id="video3" width="640" height="360" controls></video>
    <video id="video4" width="640" height="360" controls></video>
</div>

<script>
const streams = [
    'http://127.0.0.1/live/camera1.flv',
    'http://127.0.0.1/live/camera2.flv',
    'http://127.0.0.1/live/camera3.flv',
    'http://127.0.0.1/live/camera4.flv'
];

streams.forEach((url, index) => {
    const videoElement = document.getElementById(`video${index + 1}`);
    const player = flvjs.createPlayer({
        type: 'flv',
        url: url,
        isLive: true
    });
    player.attachMediaElement(videoElement);
    player.load();
    player.play();
});
</script>
```

## 🐛 故障排查

### TASK启动失败

**问题1：找不到DLL**
```
解决：确保 onnxruntime.dll 在 TASK.exe 同目录
位置：F:\EASYLOT\yfeieye-main\TASK\build\Release\
```

**问题2：模型加载失败**
```
解决：检查 weights/yolo11n.onnx 是否存在
```

### ZLM无法播放

**问题1：端口被占用**
```bash
# 检查1935端口
netstat -ano | findstr "1935"
# 杀死占用进程
taskkill /F /PID <进程ID>
```

**问题2：流不存在**
```bash
# 检查流列表
curl "http://127.0.0.1/index/api/getMediaList?secret=<你的secret>"
```

### 视频延迟太高

1. 确认使用 `zlm_lowlatency.ini` 配置
2. 检查网络带宽
3. 减少GOP大小（编辑 `RTMPEncoder.cpp`）

## 🚀 生产部署建议

### 1. 系统服务化

使用 **NSSM** 将 ZLM 和 TASK 注册为 Windows 服务：

```bash
# 下载 nssm
# 注册ZLM服务
nssm install ZLMediaKit "F:\EASYLOT\zlmediakit\MediaServer.exe"
nssm start ZLMediaKit

# 注册TASK服务
nssm install TaskAI "F:\EASYLOT\yfeieye-main\TASK\build\Release\TASK.exe" "..\..\config\test.ini"
nssm start TaskAI
```

### 2. 多摄像头部署

为每个摄像头创建独立配置文件：

```
config/
  ├── camera1.ini  (stream_name=camera1)
  ├── camera2.ini  (stream_name=camera2)
  └── camera3.ini  (stream_name=camera3)
```

启动多个TASK实例：
```bash
start TASK.exe config/camera1.ini
start TASK.exe config/camera2.ini
start TASK.exe config/camera3.ini
```

### 3. 负载均衡

- 单台服务器：3-5路1080p视频（取决于CPU）
- 多台服务器：部署多个ZLM，前端轮询或使用Nginx负载均衡

### 4. 日志管理

日志位置：
- TASK日志：控制台输出（可重定向）
- ZLM日志：`F:\EASYLOT\zlmediakit\log\`

建议配置日志轮转，避免磁盘占满。

---

## 📈 性能优化

### CPU优化

```ini
[ai]
threads=4  # 根据CPU核心数调整（推荐物理核心数-1）
```

### 内存优化

```cpp
// RTMPEncoder.cpp
_codecCtx->rc_buffer_size = _codecCtx->bit_rate / 4;  // 减小缓冲
```

### 带宽优化

```cpp
_codecCtx->bit_rate = 1500000;  // 降低码率到1.5Mbps
_codecCtx->gop_size = 25;       // 增大GOP到1秒
```

## 🔐 安全建议

1. **修改ZLM默认密钥**
   编辑 `config.ini`：
   ```ini
   secret=your_strong_random_key
   ```

2. **限制访问IP**
   在ZLM配置或使用防火墙限制访问

3. **HTTPS/WSS**
   配置SSL证书，启用加密传输

4. **认证鉴权**
   实现token验证，防止未授权访问
