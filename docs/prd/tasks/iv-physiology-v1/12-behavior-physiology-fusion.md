# 任务 12：行为事件与生理事件融合关系

类型：AFK
状态：ready-for-agent
Blocked by：任务 06、任务 07
User stories covered：21, 22

## What to build

实现行为事件和生理事件之间的融合关系。该切片完成后，同一时间窗发生倒地等行为事件和红色生理急症时，两类事件都保留，系统记录融合关系或冲突原因，生理急症仍触发医务动作。

## Acceptance criteria

- [ ] 支持按同一帧、同一轨迹、同一点位、同一身份或时间窗口建立融合关系。
- [ ] 行为事件和红色生理事件同时触发时，两类事件都保留。
- [ ] 融合成功或冲突时记录关系和原因。
- [ ] 生理急症不被行为事件覆盖、降级或吞掉。
- [ ] 事件详情可查看融合关系或冲突原因。

## Implementation notes

- `correlation_id` 是融合线索，不是可信身份。
- 融合关系不应改变红色生理急症的医务触达优先级。
- 先支持最小时间窗或 correlation 关系即可。

## Suggested tests

- 同时触发行为和生理事件时两者都存在。
- 融合关系可查询。
- 冲突原因可记录。
- 生理急症仍生成医务动作。
