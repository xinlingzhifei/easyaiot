# 任务 15：P0 验收脚本和演练数据

类型：AFK
状态：ready-for-agent
Blocked by：任务 10、任务 11、任务 12、任务 13、任务 14
User stories covered：1-30

## What to build

准备 V1-P0 八条验收脚本和演练数据，使开发、测试和现场验收可以按同一套脚本验证红色生理急症闭环。

## Acceptance criteria

- [ ] 脚本 A：正常红色急症闭环，可从样本流转到关闭。
- [ ] 脚本 B：身份不可信降级，不生成个人事件。
- [ ] 脚本 C：低质量窗口保护，不写个人事件或基线。
- [ ] 脚本 D：真实医务适配器不可用时走人工替代闭环。
- [ ] 脚本 E：医务超时升级，事件不能直接关闭。
- [ ] 脚本 F：复测为误报，证据保留并沉淀误差原因。
- [ ] 脚本 G：客户现场未 ready，报表不计真实成功。
- [ ] 脚本 H：行为与生理同时触发，两类事件都保留。

## Implementation notes

- 每条脚本都要包含输入条件、操作步骤、期望结果和不通过条件。
- 演练记录要能关联事件、证据链和报表。
- 该任务是 P0 验收门，不是普通测试补充。

## Suggested tests

- 执行八条脚本并保存演练记录。
- 每条脚本都能查到对应事件、动作、证据和报表。
- 不通过条件能被系统拦截。
