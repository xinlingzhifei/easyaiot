# 任务 06：红色生理急症创建统一 Event

类型：AFK
状态：ready-for-agent
Blocked by：任务 04、任务 05
User stories covered：4, 13, 21, 30

## What to build

实现从质量合格、可信身份明确、命中红色急症规则的 `Physiology Sample` 创建统一 `Event`。该切片完成后，红色生理急症不再只停留在告警列表，而是成为有状态、有责任链入口、有证据来源的监管事件。

## Acceptance criteria

- [ ] 合格样本加可信 `person_id` 加红色规则命中时创建个人生理事件。
- [ ] 事件进入统一事件中心，初始状态可追踪。
- [ ] 样本、身份、规则、告警输入作为事件证据来源保存。
- [ ] 红色生理事件不依赖普通行为事件存在。
- [ ] 事件创建和状态变化有日志和审计。

## Implementation notes

- `Alert` 可以作为输入和证据，但不能替代 `Event`。
- 红色生理急症的优先级不能低于普通行为事件。
- 只需先支持一条红色急症规则，后续再扩展规则引擎。

## Suggested tests

- 合格样本创建事件。
- 无可信身份时不创建事件。
- 低可信样本不创建事件。
- 事件详情能关联样本和规则证据。
