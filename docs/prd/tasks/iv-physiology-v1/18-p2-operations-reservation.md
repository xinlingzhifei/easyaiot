# 任务 18：群体趋势、健康画像和心理辅助预留

类型：HITL
状态：ready-for-human-decision
Blocked by：任务 14、任务 16
User stories covered：26, 27

## What to build

确认并预留 V1-P2 辅助运营边界，包括单所群体趋势、本地健康画像和心理辅助复核。该任务重点是合规边界、权限、审计和非独立判定标识，不要求完成完整运营产品。

## Acceptance criteria

- [ ] 明确 P2 能力不反向阻塞 P0 红色急症闭环。
- [ ] 预留群体趋势、本地健康画像、心理辅助复核的菜单、权限和审计边界。
- [ ] 所有心理辅助或画像输出默认带 `not_standalone_determination`。
- [ ] 明确心理辅助不能作为惩戒、医学诊断或监管最终判断。
- [ ] 输出后续 P2 开发前需要确认的数据范围和合规评审事项。

## Implementation notes

- 这是 P2 预留和决策任务，不建议在 P0 前实现完整功能。
- 心理辅助必须从设计上避免决定性表述。
- 敏感数据权限和导出审计要沿用任务 14 的边界。

## Suggested verification

- 人工评审 P2 边界和合规口径。
- 检查预留入口不会改变 P0 事件关闭条件。
- 检查所有辅助输出都带非独立判定标识。
