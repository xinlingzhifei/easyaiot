# 任务 16：最小治理入口

类型：AFK
状态：ready-for-agent
Blocked by：任务 09、任务 13
User stories covered：23, 24, 25, 26

## What to build

实现 V1-P1 最小治理入口，使复测结论、误差原因、低可信原因、样本证据、模型或设备版本材料能从 P0 事件闭环沉淀到治理域。

## Acceptance criteria

- [ ] 误报结论和误差原因可进入治理入口。
- [ ] 低可信原因可进入治理入口。
- [ ] 治理样本记录来源事件、样本、原因、版本和审计信息。
- [ ] 治理入口可查询、可标记处理状态。
- [ ] 治理入口不阻塞 P0 红色急症触达和关闭主链路。

## Implementation notes

- 这是最小治理入口，不是完整治理平台。
- 治理数据属于敏感数据，需要权限和审计。
- 后续模型治理和红队演练会复用该入口。

## Suggested tests

- 误报事件关闭后生成治理样本。
- 低可信窗口可沉淀治理原因。
- 无权限用户不能写治理记录。
- 治理记录可追溯来源事件。
