# 任务 10：关闭校验与证据链拦截

类型：AFK
状态：ready-for-agent
Blocked by：任务 07、任务 08、任务 09
User stories covered：2, 7, 10, 11

## What to build

实现红色生理事件关闭校验和证据链拦截。红色事件可以先触发急症动作，但在普通关闭前必须满足动作、复测、证据、责任链、readiness 和权限要求。

## Acceptance criteria

- [ ] 缺医务复测或无法复测审批时不能普通关闭。
- [ ] 缺医务、干警、领导动作最终状态时不能普通关闭。
- [ ] 缺关键证据链材料时进入补充或返工状态。
- [ ] 关闭人必须具备关闭权限。
- [ ] 关闭、驳回、补充材料均进入审计。

## Implementation notes

- 证据链缺口不应阻塞急症派发，但必须阻塞普通关闭。
- 关闭校验应返回可读的失败原因。
- 审计员需要能复盘关闭校验依据。

## Suggested tests

- 缺复测关闭失败。
- 缺动作关闭失败。
- 补齐材料后关闭成功。
- 无权限用户关闭失败。
