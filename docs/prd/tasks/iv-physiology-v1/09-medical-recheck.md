# 任务 09：医务复测任务和复测回填

类型：AFK
状态：ready-for-agent
Blocked by：任务 08
User stories covered：6, 7, 8, 23

## What to build

实现医务复测任务和回填。该切片完成后，医务人员可以对红色生理事件回填实际复测体征、医学判断、真异常/误报结论、误差原因、SOP 结果和附件；无法复测时可提交原因并进入审批。

## Acceptance criteria

- [ ] 红色生理事件能生成医务复测任务。
- [ ] 医务人员能回填复测指标、医学判断、SOP 结果和附件。
- [ ] 支持真异常、误报、无法复测等结论。
- [ ] 无法复测原因进入审批或审核流程。
- [ ] 复测记录与事件、样本、动作和证据链关联。

## Implementation notes

- 医务复测不是通知成功，也不是动作回执。
- 误报事件不能删除原始事件和证据。
- 复测结论后续要流入治理入口。

## Suggested tests

- 医务复测任务创建。
- 复测回填成功。
- 无法复测未审批时不能关闭事件。
- 误报结论保留原始证据。
