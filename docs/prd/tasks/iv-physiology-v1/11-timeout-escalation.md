# 任务 11：医务和干警超时升级

类型：AFK
状态：ready-for-agent
Blocked by：任务 08、任务 09
User stories covered：3, 5, 9

## What to build

实现医务和干警动作超时升级。该切片完成后，医务未接收、未复测、干警未到场或未处置时，系统能记录超时、催办并升级到监区值班长、指挥中心或带班领导。

## Acceptance criteria

- [ ] 可配置医务接收、复测回填、干警到场等超时阈值。
- [ ] 超时后动作状态进入 `timeout`。
- [ ] 系统生成催办和升级记录。
- [ ] 事件详情展示超时和升级链路。
- [ ] 超时事件不能绕过复测或审批直接关闭。

## Implementation notes

- 超时升级是责任链的一部分，不是普通通知失败。
- 升级记录应进入证据链和报表。
- 阈值可以先做最小配置，不需要复杂规则引擎。

## Suggested tests

- 医务接收超时生成升级。
- 干警到场超时生成升级。
- 超时事件关闭校验失败。
- 报表统计超时升级数。
