# 任务 05：低可信窗口保护与匿名质量统计

类型：AFK
状态：ready-for-agent
Blocked by：任务 03
User stories covered：15, 16, 29

## What to build

实现低可信生理窗口保护。该切片完成后，ROI 丢失、遮挡、强运动、热源干扰、厚被遮挡、设备未标定、有效采样不足等低可信样本不会创建个人生理事件，也不会写入个人基线，而是进入匿名质量统计或点位整改。

## Acceptance criteria

- [ ] 样本能标记低可信原因。
- [ ] 低可信样本不创建个人生理事件。
- [ ] 低可信样本不写入个人基线。
- [ ] 低可信样本进入匿名质量统计、点位整改或人工复核。
- [ ] 低可信原因可查询、可审计、可报表统计。

## Implementation notes

- 低可信不是误报结论，而是个人事件创建前的质量保护。
- 匿名质量统计不能反向暴露个人敏感信息。
- 该任务可与任务 04 并行。

## Suggested tests

- ROI 丢失样本进入匿名质量统计。
- 未标定点位样本不创建个人事件。
- 低可信原因在查询和报表中可见。
- 低可信样本不会污染个人基线。
