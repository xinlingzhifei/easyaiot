# 任务 17：生理模型治理预留

类型：AFK
状态：ready-for-agent
Blocked by：任务 16
User stories covered：25, 26

## What to build

为生理模型治理预留版本、评审、影子模式、灰度、冠军-挑战者和回滚的数据与页面入口。该任务不要求完成完整模型治理运营，但必须保证后续不会重写 P0 样本和治理数据结构。

## Acceptance criteria

- [ ] 每个生理样本可追溯模型或设备版本。
- [ ] 可记录模型版本、设备版本、参数版本和上线状态。
- [ ] 可把新版本评估材料放入治理入口。
- [ ] 预留影子模式、灰度、冠军-挑战者、回滚的记录结构。
- [ ] 模型治理预留不影响红色急症主通道安全。

## Implementation notes

- V1-P0 不要求完整模型治理平台。
- 新模型不得绕过 readiness、评审和回滚策略直接影响主通道。
- 可以先用状态和记录结构预留，不做复杂调度。

## Suggested tests

- 样本版本信息可追踪。
- 治理入口能关联模型版本材料。
- 未评审版本不能标为生产主通道。
- 预留字段不破坏 P0 查询。
