# 任务 14：敏感证据权限、导出审批和审计

类型：AFK
状态：ready-for-agent
Blocked by：任务 07、任务 10
User stories covered：10, 11, 12, 27

## What to build

实现生理证据、医务判断、事件关闭、治理写入和导出审批的权限与审计边界。该切片完成后，敏感生理证据和医务结论不会通过普通告警权限暴露，导出行为可追责。

## Acceptance criteria

- [ ] 增加生理证据查看、医务复测、治理写入、事件关闭、导出审批等权限。
- [ ] 非授权角色不能查看医务判断和敏感生理证据。
- [ ] 敏感证据导出需要审批。
- [ ] 查看、回填、关闭、审批、导出均有审计记录。
- [ ] 心理辅助或健康画像相关预留输出带 `not_standalone_determination`。

## Implementation notes

- 权限命名应接入现有菜单权限风格。
- 导出审批不需要一开始做复杂流程，但必须可审计。
- 心理辅助标识从 P0 开始预留。

## Suggested tests

- 无权限用户查看敏感证据失败。
- 有权限用户查看成功并写审计。
- 导出审批记录可查询。
- 心理辅助标识存在且不可作为 P0 判定依据。
