# 任务 07：事件中心列表、详情和状态时间线

类型：AFK
状态：ready-for-agent
Blocked by：任务 06
User stories covered：4, 10, 30

## What to build

实现红色生理事件在事件中心的列表、详情和状态时间线。该切片完成后，指挥中心和值班人员可以从统一事件中心查看生理急症事件，而审计人员可以复盘事件生命周期。

## Acceptance criteria

- [ ] 事件中心列表能展示红色生理事件。
- [ ] 事件详情能展示状态、责任链、样本、证据、动作、复测、readiness 和审计摘要。
- [ ] 状态时间线展示创建、派发、接收、处置、复测、关闭校验和关闭。
- [ ] 用户从列表进入详情后，不需要跳到告警列表才能理解事件。
- [ ] 详情页权限能区分普通查看和敏感证据查看。

## Implementation notes

- 页面应服务高频处置和审计复盘，避免做成纯展示大屏。
- 告警列表可以继续存在，但不能替代事件中心。
- 状态字段应使用任务 01/06 的事件语义。

## Suggested tests

- 事件列表查询。
- 事件详情渲染。
- 状态时间线排序正确。
- 无权限用户看不到敏感医务或证据字段。
