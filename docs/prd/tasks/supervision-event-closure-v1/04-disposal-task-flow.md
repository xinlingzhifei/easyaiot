# 任务 04：处置任务派发、接收和处理提交

类型：AFK
状态：ready-for-agent
Blocked by：任务 02、任务 03

## What to build

实现事件处置任务的派发、接收和处理提交，让监管事件落实到具体责任单位、责任人和现场处置记录。

## Acceptance criteria

- [ ] 指挥中心或授权角色能派发处置任务。
- [ ] 责任人能在“我的待办”中接收任务。
- [ ] 处理人能填写到场时间、处置说明、现场结果和附件。
- [ ] 提交后事件进入待复核或待关闭校验。

## Implementation notes

- 现场处理记录不能修改原始告警。
- 处置任务状态独立于事件状态，但应同步写入事件时间线。

## Suggested tests

- 派发任务成功。
- 责任人接收并提交处理。
- 非责任人不能伪造处理记录。
