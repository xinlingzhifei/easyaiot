# 任务 05：复核与退回补充

类型：AFK
状态：ready-for-agent
Blocked by：任务 04

## What to build

实现复核记录和退回补充。支持普通复核、医务复核、康复/心理复核和领导确认。

## Acceptance criteria

- [ ] 复核人能通过或驳回处置结果。
- [ ] 驳回必须填写原因。
- [ ] 驳回后事件进入退回补充。
- [ ] 复核记录进入证据链和时间线。

## Implementation notes

- 医务和康复/心理复核属于敏感数据，后续任务 08 需要做权限隔离。
- 复核通过不等于关闭，仍需进入关闭校验。

## Suggested tests

- 复核通过进入关闭校验。
- 复核驳回后处理人可补充再提交。
- 复核记录不可被普通处理人篡改。
