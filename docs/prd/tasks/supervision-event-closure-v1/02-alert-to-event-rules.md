# 任务 02：告警转监管事件规则

类型：AFK
状态：ready-for-agent
Blocked by：任务 01

## What to build

实现告警转监管事件的最小规则，支持从现有告警生成监管事件，并避免重复创建未关闭事件。

## Acceptance criteria

- [ ] 告警列表或详情能生成监管事件。
- [ ] 已有关联未关闭事件时显示“查看监管事件”。
- [ ] 规则能区分自动生成、人工确认后生成、只归档、不生成。
- [ ] 事件生成时带入告警、设备、图片、录像和任务上下文。

## Implementation notes

- MVP 可先内置规则，后续再做配置化。
- 高危事件类型如倒地、突发疾病、生理红色急症默认自动生成事件。

## Suggested tests

- 普通告警人工生成事件。
- 高危告警自动生成事件。
- 同一告警不能重复生成多个未关闭事件。
