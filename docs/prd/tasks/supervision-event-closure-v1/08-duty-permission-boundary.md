# 任务 08：职责隔离和数据权限

类型：AFK
状态：ready-for-agent
Blocked by：任务 03、任务 04、任务 05、任务 06

## What to build

实现监管事件闭环的职责隔离和敏感数据权限，防止越权、代办和伪闭环。

## Acceptance criteria

- [ ] 指挥中心能调度，但不能填写医务结论。
- [ ] 现场处理人能提交现场记录，但不能关闭 L3/L4。
- [ ] 医务、康复/心理记录有单独数据权限。
- [ ] 值班领导能审批 L3/L4 和无法确认。
- [ ] 系统管理员不能伪造业务处置、复核和关闭记录。

## Implementation notes

- 技术配置权和业务处置权必须分离。
- 敏感内容可先做摘要可见、详情授权可见。

## Suggested tests

- 普通处理人关闭 L3/L4 被拒绝。
- 非授权角色不能查看医务/心理详情。
- 管理员不能代写处置记录。
