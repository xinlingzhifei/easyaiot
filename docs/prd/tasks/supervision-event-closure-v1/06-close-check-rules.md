# 任务 06：关闭校验规则

类型：AFK
状态：ready-for-agent
Blocked by：任务 04、任务 05

## What to build

实现 L1-L4 的关闭校验规则，防止缺责任链、缺复核、缺证据或缺授权时静默关闭。

## Acceptance criteria

- [ ] L1 至少要求处理说明、结果分类和操作日志。
- [ ] L2 至少要求责任人、到场记录、现场结果和证据。
- [ ] L3 要求复核意见、领导确认和证据链。
- [ ] L4 要求医务/康复复核、现场处置、领导关闭或无法复核审批。
- [ ] 关闭结果使用受控字典。

## Implementation notes

- 误报也必须保留原始告警和误报原因。
- “无法确认”必须受控，L3/L4 必须领导审批。

## Suggested tests

- 缺复核时 L3/L4 不能关闭。
- 误报关闭保留原因和确认人。
- 无权限角色不能关闭高等级事件。
