# 任务 07：证据链和事件时间线

类型：AFK
状态：ready-for-agent
Blocked by：任务 03、任务 04、任务 05、任务 06

## What to build

实现监管事件证据链和完整时间线，支持事后督察复盘。

## Acceptance criteria

- [ ] 证据链包含原始告警、图片、录像、设备、点位、人员、任务、处置、复核、关闭和操作日志。
- [ ] 时间线展示创建、派发、接收、处置、复核、驳回、补充、关闭校验和关闭。
- [ ] 证据缺口可被关闭校验识别。

## Implementation notes

- 图片和录像继续复用现有 MinIO、录像空间和播放器入口。
- 证据链是索引和审计包，不一定复制原始文件。

## Suggested tests

- 事件详情能展示时间线。
- 事件详情能打开原始图片和录像。
- 证据缺失会阻止需要证据的事件关闭。
