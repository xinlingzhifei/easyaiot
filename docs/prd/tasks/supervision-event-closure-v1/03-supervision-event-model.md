# 任务 03：监管事件模型与状态机

类型：AFK
状态：ready-for-agent
Blocked by：任务 01

## What to build

实现监管事件基础模型和状态机，承载事件类型、等级、来源告警、状态、责任单位、创建人和时间线。

## Acceptance criteria

- [ ] 事件可创建、查询、查看详情。
- [ ] 事件状态可从 `created` 流转到派发、接收、处置、复核、关闭校验和关闭。
- [ ] 状态变化写入时间线。
- [ ] 事件详情关联原始告警、设备、图片和录像入口。

## Implementation notes

- 状态语义应服务监管事件，不要复用告警通知状态。
- 事件等级允许因规则升级，但降级必须留痕并经授权确认。

## Suggested tests

- 创建事件成功。
- 状态流转写入时间线。
- 事件详情能读取告警证据素材。
