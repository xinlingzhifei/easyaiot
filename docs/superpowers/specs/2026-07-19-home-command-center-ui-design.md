# 首页大屏指挥中心 UI 重构设计

## 背景

现有首页采用深色三栏监控布局，功能齐全，但视觉层级被大量卡片、描边、渐变和多种强调色稀释。中央视频区与左右侧栏权重接近，指挥中心最重要的“发现异常、定位画面、进入处置”链路不够突出。

本次只重构首页大屏的信息架构、视觉系统和响应式呈现，不改变现有接口、视频播放、设备选择、AI 开关、告警回放、预案及管理后台跳转等业务行为。

## 方案比较与选择

### 方案 A：沉浸式数字孪生

以强光效、地图或三维空间作为视觉中心。展示感最强，但真实监控画面和告警可读性会被装饰层干扰，且移动端难以保持一致体验。

### 方案 B：高密度安防终端

压缩间距并最大化数据密度。适合长期坐席操作，但学习成本高，小屏与普通浏览器下容易显得拥挤。

### 方案 C：冷静型指挥中枢（采用）

以中央视频墙为第一层级，设备树与告警队列作为两条辅助轨道；减少独立卡片和发光效果，以连续状态带、细线框架和明确的状态色建立秩序。该方案在大屏可形成专业指挥感，也能自然重排到桌面和手机端。

## 核心设计原则

1. 视频优先：中央视频工作区始终占据最大面积，当前画面通过青色细框明确选中状态。
2. 告警可行动：琥珀色只表示需要关注或处置的事件，红色只用于严重故障，不作为普通装饰色。
3. 状态连续：关键指标采用一条横向 KPI 状态带，不再重复使用 2×2 等权统计卡。
4. 层级克制：面板使用近黑蓝色面和 1px 结构线，不使用大面积渐变、厚重阴影或无意义圆角。
5. 任务重排：手机端不是缩小整张大屏，而是按“概览 → 当前视频 → 活跃告警 → 最近告警”重排。

## 视觉系统

### 色彩

- 页面背景：`#061017`
- 一级面板：`#0A1720`
- 二级面板：`#0E202B`
- 结构线：`#1D3541`
- 主文字：`#EDF7FA`
- 次级文字：`#91A8B4`
- 弱文字：`#617A86`
- 运行/选中：`#26D5E4`
- 正常：`#3DDC97`
- 待处置：`#F5B942`
- 严重故障：`#FF5F6D`

### 字体

- 标题：Funnel Sans，代码实现时回退到项目现有无衬线字体。
- 正文：Inter，代码实现时使用项目现有字体栈。
- 时间、数值和技术标签：IBM Plex Mono 或等宽字体栈。

### 形态

- 主要面板圆角 0–3px，状态胶囊可使用完整圆角。
- 面板边界使用 1px 细线；选中视频可使用 2px 青色边界。
- 不给每条信息单独套卡片，只有结构容器、可点击列表项和关键事件需要独立表面。

## 1920×1080 指挥中心布局

### 顶部全局栏

- 左侧：yFeiEye 标识、平台名称和英文运行标签。
- 中部：当前监控域。
- 右侧：系统健康、时钟和操作员入口。
- 高度 72px，避免大型装饰标题占用工作区。

### KPI 状态带

在线设备、实时画面、启用模型、今日告警和存储余量横向排列，用细分隔线组织，不使用五张独立卡片。

### 主工作区

- 左栏 284px：设备搜索、区域树、在线状态和快捷视图。
- 中栏自适应：视频工具栏、2×2 实时视频墙和活跃事件处置条。
- 右栏 328px：告警过滤和按优先级排列的处置队列。

### 活跃事件条

只突出当前最需要处置的一条事件，包含预览、时间、设备、模型、置信度和“进入处置”动作，避免与右侧完整告警队列重复竞争。

## 普通浏览器布局

基准画布为 1440×900：

- 顶部栏缩至 64px，状态带缩至 68px。
- 左栏缩至 248px，右栏缩至 300px。
- 保持 2×2 视频墙，不改变核心操作位置。
- 告警行降低高度，完整保留五条可见队列。
- 当宽度继续下降到 1180px 以下时，设备树和告警队列改为可唤出的抽屉，视频工作区保持主视图。

## 手机端布局

基准画布为 390×844：

1. 64px 紧凑品牌栏，保留健康状态和告警入口。
2. 当前监控域独立一行，可点击切换。
3. 仅展示在线设备、实时画面、今日告警三个核心指标。
4. 主体固定为单画面，设备列表通过工具栏抽屉打开，AI 状态保留为显式开关。
5. 当前活跃告警紧邻视频，提供直接处置入口。
6. 最近告警以紧凑列表呈现，底部导航承载监控、设备、告警和个人入口。

## 交互与状态

- 设备选择、视频分屏、预案、AI 开关和告警点击沿用现有事件与数据流。
- 加载态使用局部骨架或“检查中”，不得用假数字覆盖真实数据。
- 空状态说明当前范围无设备或无告警，并保留刷新或切换范围入口。
- 接口失败在对应区域内呈现，不连续弹出全局消息。
- 当前选中、在线、待处置和故障状态不能只依赖颜色，需同时保留文字、图标或边框差异。

## 代码映射

- `WEB/src/views/dashboard/monitor/index.vue`：页面网格、响应式断点和移动端重排。
- `components/Header.vue`：全局栏与 KPI 状态带。
- `components/Sidebar.vue`：移除重复统计卡，聚焦设备导航。
- `components/VideoMonitor.vue`：视频工具栏、画面边界与活跃事件条。
- `components/AlarmPanel.vue`：告警队列层级、过滤和紧凑列表。
- 其他组件只在实现本设计所必需时做最小样式调整，不改业务契约。

## 验收标准

1. 1920×1080、1440×900 和 390×844 均无横向溢出、遮挡或不可达操作。
2. 1920×1080 下中央视频工作区是最大视觉区域，左右栏不与其争夺主焦点。
3. 手机端按任务顺序重排，不出现三栏等比例缩放。
4. 原有设备选择、视频播放、分屏、预案、AI、告警回放和后台入口保持可用。
5. 状态色遵循青色运行、绿色正常、琥珀待处置、红色严重故障的单一语义。
6. 生产构建通过；若仓库已有类型检查基线故障，必须区分本次新增问题与既有问题。
7. Pencil 画布的三个目标尺寸均通过布局问题检查。
