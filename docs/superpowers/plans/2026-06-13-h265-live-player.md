# H265 Live Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add frontend live-player routing so GB28181 streams using H265 and other common camera codecs can play through the existing WASM player.

**Architecture:** Add a pure strategy module under `WEB/src/views/camera/utils/`. Use it from WVP play URL selection and from the shared Jessibuca wrapper. Keep existing call sites stable by making the wrapper choose Jessibuca or EasyWasm internally.

**Tech Stack:** Vue 3, TypeScript, Jessibuca, EasyWasmPlayer, esno tests, Vite build.
