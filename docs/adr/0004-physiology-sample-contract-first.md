# Normalize Upstream Physiology Samples First

The V1-P0 goal is to prove the supervision emergency loop, not to require a fully self-developed physiology algorithm before any delivery can pass. We will prioritize upstream infrared, near-infrared, thermal-imaging device, or vendor SDK output for V1-P0, while yFeiEye owns the unified `Physiology Sample` contract, quality labels, model or device version, and readiness checks; a self-developed worker can act as fallback, run in parallel, or replace upstream sources later without blocking the first red emergency loop.
