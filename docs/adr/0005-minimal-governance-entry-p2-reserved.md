# Ship Minimal Governance Entry Before Full P2 Operations

The source requirement includes physiology data governance, model governance, red-team drills, failure-mode libraries, and auxiliary psychology or profile views. Those capabilities matter, but the first delivery must not block the V1-P0 red emergency loop.

We will ship V1-P1 with a minimal usable governance entry. It must accept recheck conclusions, error reasons, low-confidence reasons, sample evidence, and model or version review material so governance data can flow from real handling.

V1-P2 may begin as reserved data structures, permissions, audit records, and navigation entries. It does not need to fully operate trend profiles, psychology assistance, or long-term governance workflows before V1-P0 is proven.

Psychology or profile outputs must keep a non-determinative marker such as `not_standalone_determination` from V1-P0 onward. They must not become punishment, diagnosis, or final supervision judgment by themselves.

This keeps the life-safety loop first while avoiding a later rewrite of governance, audit, and compliance boundaries.
